# Laser Vault Heist

A standalone C++17 / OpenGL 3.3 core stealth game for Computer Graphics Fundamentals.

Student: Nurbek Yerbulekov  
Group: SE-2428

## Development status

Implementation is in progress. See [requirements and evidence](docs/requirements-evidence.md). No final release has been declared.

The project is a single-author teaching example. The source course assignment describes teams of 3–5; no additional contributors or completed human assessments are implied.

## Scope

One furnished vault room, moving thin-box lasers, first-person walking and crouching, alarm/retry, animated safe, rotating spotlights, live CCTV, a custom rigged thief, and three scene interactions.

## Build

The build uses CMake and a C++17 compiler. The course starter and TA machine configuration were not supplied; CMake is an explicit assumption. Dependencies are vendored. Complete commands and validated platforms will be recorded after the first successful build.
